# PokeWatch for Apple Watch

A watchOS (SwiftUI) port of the same game as the Wear OS and Garmin apps:
the same rules (`Game/Pet.swift` is a line-for-line port of `pet.cpp`), the
same screens drawn in TamaPoke's 466×466 layout and scaled to the watch, and
the redesigned starter choice. Needs watchOS 10 (Apple Watch Series 4 or newer).

| Path | What |
| --- | --- |
| `Game/` | Game logic, sprite readers, text (no UI code, unit tested) |
| `Game/Tables.swift` | Generated by `tools/gen_tables.py`, like the other ports' tables |
| `PokeWatch/` | The app: one SwiftUI `Canvas` redrawn ~10×/s, touch and Digital Crown |
| `Tests/` | The Wear OS game tests, ported to XCTest |
| `mons/` | Sprites, filled by `tools/fetch_sprites.py`, never committed |
| `project.yml` | XcodeGen spec; the `.xcodeproj` is generated |

## Controls

Same as Wear OS: tap the pet to pet it, the four bottom buttons (food, play,
light, bath), swipe up for the stats card, down for settings, sideways for
the Pokédex, hold the pet for 3 s to release it. The Digital Crown pages the
Pokédex, the card and the starters. There's no back button on the watch, so
screens close the way they do on the original: tap the card to close it, tap
the top of the Pokédex or minigame, swipe the gallery back to page 1.

## Build on your Mac

```sh
brew install xcodegen
pip3 install pillow
python3 tools/fetch_sprites.py      # sprites for your own build (a few minutes)
cd watchos && xcodegen               # makes PokeWatch.xcodeproj
open PokeWatch.xcodeproj
```

In Xcode pick your team under Signing & Capabilities, choose your watch (or a
watch simulator) and press Run. Without sprites the app still runs and shows a
"?" (or the built-in art for the first nine Pokémon).

## Keeping it private

Nothing here puts the app on the App Store. Two private ways to get it onto a
friend's watch, both with a paid Apple Developer Program membership:

**TestFlight, internal testing (what `codemagic.yaml` does).** Builds go to
App Store Connect but are only visible to people you add to your team, and
internal builds skip Beta App Review. Each build works for 90 days, so push a
new build before then.

1. In App Store Connect, create the app record (platform **iOS**: watch-only
   apps are listed under iOS) with the bundle ID from `project.yml`.
2. Users and Access: invite your friend's Apple ID with a minimal role (for
   example Marketing or Customer Support). Once they accept, add them under
   the app's TestFlight > Internal Testing.
3. They install TestFlight on the iPhone paired with the watch, accept the
   invite and install PokeWatch; it appears on the watch.

Don't add external testers: that sends the build to Beta App Review.

**Ad Hoc.** No App Store Connect at all: the build is signed for a list of
registered devices and is good for a year.

1. Register your friend's watch UDID under Certificates, IDs & Profiles >
   Devices (they can read it in Xcode's Devices window or Finder via the
   paired iPhone).
2. In `codemagic.yaml` set `distribution_type: ad_hoc` and delete the
   `app_store_connect` publishing block. Download the `.ipa` artifact.
3. Install it from Xcode (Window > Devices and Simulators, select the watch,
   drag the `.ipa` onto Installed Apps) with the watch's iPhone connected to
   your Mac.

## Codemagic setup (TestFlight)

1. App Store Connect > Users and Access > Integrations: create an API key
   (App Manager role). In Codemagic, add it under Team settings > Team
   integrations > Developer Portal and name it `PokeWatch ASC key` (or change
   the name in `codemagic.yaml`).
2. Codemagic > Team settings > Code signing identities: generate or upload an
   Apple Distribution certificate, then fetch the App Store profile for
   `com.notacultleader.pokewatch` (Codemagic can create it through the key).
3. Put the app's numeric Apple ID in `APP_STORE_APPLE_ID` in `codemagic.yaml`.
4. Start the `Apple Watch to TestFlight` workflow. It downloads the sprites,
   generates the project, runs the game tests, archives, and uploads.

If the bundle ID is taken, change it in `project.yml` and `codemagic.yaml`.
